# Déficit Calórico
Web app (PWA) para registrar calorías, macros, peso, medidas y un plan de fuerza en casa.
Abre `index.html` desde un hosting estático (p. ej. GitHub Pages) y usa "Añadir a pantalla de inicio" en el móvil.
Los datos se guardan en el navegador (localStorage); usa Perfil → Copia de seguridad.
